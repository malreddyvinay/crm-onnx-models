A new feature has been released in Microsoft Power Apps to ***Clear all objects*** in the Solution, while adding the existing Table’s components.

By default, when we add an existing Table in the solution, we can see the list of all objects selected.

On click of Clear all objects, all the selected objects will be removed.

Objects removed.

It is a simple feature, but it saves more time to remove the objects in a single click, without unselecting each and every object individually.

**Note**: I observed this feature in my environment which has Dataverse version of 9.2.25013.188.
